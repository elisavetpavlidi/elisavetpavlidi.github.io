# Elisavet Pavlidi

Personal academic website of Elisavet Pavlidi, a Physics undergraduate specializing in astrophysics at the National and Kapodistrian University of Athens.

## Website

https://elisavetpavlidi.github.io/

## Publishing

GitHub Pages publishes the root directory of the `main` branch. The site uses HTML, CSS, SVG and JavaScript and does not require a build step.

## Files

* `index.html`: website content, responsive styling and illustrations.
* `robots.txt`: crawler access and sitemap location.
* `sitemap.xml`: canonical home page.
* `.nojekyll`: serve the static files directly.
